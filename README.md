# 群成员获取插件 (astrbot_plugin_get_members)

一个为 AstrBot 设计的轻量级管理工具插件，允许管理员通过指令快速导出当前群聊的所有成员 QQ 号与全局昵称，便于进行群组迁移、数据统计与备份。

> **声明**：本插件的核心代码由 DeepSeek（AI）辅助生成，经人工调试与整理，仅供学习交流使用。

---

## 主要特性

- **权限校验机制**：仅限群主或管理员执行，普通成员触发时会自动拦截，保障群数据安全。
- **精确数据导出**：输出格式为“QQ昵称：QQ号”，方便直接复制至 Excel、数据库或脚本中使用。
- **并发限流保护**：获取成员昵称时采用异步信号量（Semaphore）限制并发数为10，有效规避平台风控与账号封禁风险。
- **自动排序**：结果按 QQ 号从小到大进行升序排列，方便查阅与比对。
- **智能分段发送**：针对大群（500人以上）的长文本输出，自动按每100人一段进行分页发送，防止消息因超长被系统截断；群成员较少时，列表可在单条消息内完整输出，便于管理员快速熟悉群内成员，一次认全所有人。

## 安装方法

### 方式一：通过 WebUI（推荐）
1. 进入 AstrBot WebUI -> 插件管理 -> 插件市场。
2. 搜索 **获取群成员列表** 或 **astrbot_plugin_get_members**。
3. 点击安装并启用。

### 方式二：手动安装
1. 在 `data/plugins/` 目录下新建文件夹，命名为 `astrbot_plugin_get_members`。
2. 将以下文件放入该文件夹：
   - `main.py`
   - `metadata.yaml`
   - `README.md`
3. 重启 AstrBot 或在 WebUI 中重载插件。

---

## 使用方法

1. 确保发送者拥有群聊的管理员或群主权限。
2. 在群聊中发送指令：`/get_members`
3. 机器人将返回该群所有成员的全局昵称和对应的 QQ 号。针对人数较少的群组，消息将一次性完整输出，方便管理员快速认全所有成员。

### 示例输出

```text
📋 群 123456789 成员列表（共 5 人）：

张三：123456789
李四：234567891
王五：345678912
赵六：456789123
孙七：567891234
```

## 前置条件

- 机器人账号必须已加入目标群聊。
- 机器人账号需具备获取群成员信息的权限（接口所需，无需机器人本身为管理员）。
- 适配器为 `aiocqhttp`（NapCat / OneBot v11）。

## 常见问题

**Q：普通用户执行 `/get_members` 会怎样？**  
A：插件会直接返回“权限不足”的提示，不会泄露任何群成员信息。

**Q：支持多群操作吗？**  
A：支持。指令仅在当前触发的群聊中生效，返回当前群的成员列表，多群数据互不影响。

**Q：长列表消息会刷屏吗？**  
A：系统已内置智能分段机制，仅当内容超出平台消息长度限制时才会触发分页发送。
